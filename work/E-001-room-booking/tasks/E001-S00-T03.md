## Dispatch note
- pnpm needs the sandbox off (T-01 evidence note 3).
- `src/lib/openapi.ts`: `@asteasolutions/zod-to-openapi` registry. Register only `GET /api/health`, response `{ status: "ok" }`. Server actions are not in OpenAPI.
- `scripts/gen-openapi.ts`: writes `docs/api/openapi.yaml` (OpenAPI 3.1). With `--stdout` it prints the YAML and writes nothing, which is how this task proves it works. T-06 runs the real write (`pnpm docs:openapi`), because `docs/` belongs to T-06.
- `src/lib/time.ts` (ADR-0009): pure helpers, no Prisma, no `next/*`. Convert between UTC instants and office-local wall time for an IANA zone; local day bounds; 15-minute step check; whether a local time falls inside opening hours; DST gap detection (a local time that does not exist) and repeated hour detection; format "Mon 16 Nov 2026" and 24-hour "14:30"; zone short name label. TSDoc on each export. Unit tests are T-05's (`tests/unit/lib/time.test.ts`): write the functions so they are easy to test with fixed instants.
- `next.config.ts`: keep T-01's settings (`poweredByHeader`, `reactStrictMode`, `serverActions.bodySizeLimit` 2 MB). Add `serverActions.allowedOrigins` from `APP_ORIGIN` host only, and static headers on every route: HSTS `max-age=31536000; includeSubDomains`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `X-Frame-Options: DENY`.
- `src/proxy.ts` (Next.js 16 name for middleware; read the installed Next version first): make a per-request nonce, set `Content-Security-Policy` with `script-src 'self' 'nonce-<n>' 'strict-dynamic'`, `object-src 'none'`, `base-uri 'self'`, `frame-ancestors 'none'`, and pass the nonce to the app through a request header. Also accept `x-request-id` or make one, and set it on the response (logging.md). No auth logic here: S-01 owns sessions.
- Header and proxy tests are T-05's (`tests/integration/house/headers.test.ts`).
